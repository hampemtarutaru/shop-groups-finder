## 設計・安全確認
1. JSONの`groups.id`重複、brand.groupの参照先を確認。各IDは安全なファイル名として検証。
2. 題名・概要・会社・ブランド・沿革はHTMLエスケープ。外部リンクは`https:`だけ許可。出典を直接明記。
3. 各ブランドから店名検索URL `/?q=` に戻れる。
4. 既存データ更新に合わせてローカル再生成可。**公開時は更新作業に自動組み込み**、独立ページの放置や古い情報の固定化を防ぐ必要あり。
5. 本番リリースするなら原文重複の質/企業分類の正確性、独立URL、canonical、サイトマップ、索引へのリンク、リンク回遊、モバイル画面と検索コンソールでの実観測が必須。大量に自動公開すればSEO流入するとは限らない。
