## 2026-11-11｜表示の誤認防止・小画面QA

### リンクの表記を修正した理由
現行正本 `public/data.json` では、ブランドの `source` が必ずしも個別ブランドの専用サイトを指すとは限らない。対象60件について参照URLの分布を調べると、U.S.M.H の13件は **すべて** `https://www.usmh.co.jp/about`、すかいらーく29件はグループのブランド一覧・ブランド概要ページに集中している。これを各ブランドの「個別の公式情報」と呼ぶと、個別運営会社まで証明する根拠だと誤認されるおそれがある。

そのため画面では **「登録出典（公式・別タブ）」** と表示し、「ブランド専用ページとは限らない」「法人の対応関係を全件照合済みではない」と説明する。既存の `source` URLそのものは改変せず、各ブランド名を含む `aria-label` をリンクに付けて区別しやすくした。

ペアは「現行登録データ上の**同一の運営法人**」に属する場合だけ生成し、どちらかのブランドの会社ラベルが変われば生成時に例外を投げる。登録時点の法人分類であり、現在の全店舗で直営やFCの運営者が同じことまで断定しない。新しい事実や外部リンクは追加しない。

`scripts/k089_hierarchy_poc.test.mjs` にペアの同社一致と会社変更時に生成を拒否するテストを追加。`qa/hierarchy-poc/browser-smoke.mjs` は320/375/768/1280pxでカード数・横幅・44pxタップ領域・会社欄へのアンカーを検査する。正式本番に向けたUI採用は引き続き保留。
